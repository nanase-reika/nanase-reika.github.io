七瀬玲華Reika Nanase

Romance Novelist

ロマンス作家。年齢は、物語の中の時間と同じく、内緒です。

王宮の大広間で婚約破棄を告げられる令嬢も、四十二歳で離婚届を出した夜に初恋の人と再会する女性も、私にとっては同じひとりのヒロインです。

奪われた名前、言えなかった言葉、手放しかけた自分の時間。それを誰かに返してもらうのではなく、自分の手で取り戻す。そして、選んだ人の隣で笑う。そんな物語を書いています。

舞台は、西洋風の王宮、平安の宮廷、大正の浅草、そして今の日本。時代が変わっても、誇りを取り戻す瞬間の美しさは変わらないと信じています。
